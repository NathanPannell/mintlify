## Executive summary

This handbook brings seven ongoing projects into one place. Start with a project's overview for its purpose and current state, open its deployment guide before shipping a change, and use its troubleshooting page when something fails. Every page starts with a summary for you, followed by the detail an agent needs.

The current park app is **Parkdex**. **Legacy Parkdex** is the earlier implementation. They have different repositories and release procedures, even where they share product history.

## Agent context

This source audit is dated **September 29, 2026**. Each project page identifies its inspected source and verification limits. A successful workflow, merged PR, configured domain, or historical release note alone does not prove that a current deployment is healthy. Verify the intended commit and affected journeys at the target host during delivery.

The handbook records implementation and operational knowledge. It does not grant permission to promote a source project to production, change credentials, delete shared resources, or change its release policy. Apply the source project's current instructions before acting.

For a new task, use the [reading workflow](/quickstart). Resolve contradictions in the original sources before treating an old note as a command.
