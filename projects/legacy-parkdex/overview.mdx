## Executive summary

Legacy Parkdex is the earlier map application in `NathanPannell/parkdex`. The canonical local checkout is `C:\repo\parkdex-workspace\parkdex`. The project contains a static Next.js frontend, a Python API, and an Android app built from the frontend. The app uses Vercel for the frontend, Railway for the API, and Neon for PostgreSQL.

The Legacy app hosts are `staging.map.parkdex.app` and `map.parkdex.app`. The landing site owns `staging.parkdex.app`, `parkdex.app`, and `www.parkdex.app`. Keep the OAuth issuer and MCP identity on the landing domains. This project is separate from the current Parkdex repository, `NathanPannell/parkdex-kip`.

## Environment map

| Environment | Branch | App origin | Railway API | Neon database branch |
| --- | --- | --- | --- | --- |
| Staging | `staging` | `https://staging.map.parkdex.app` | `https://api-staging-882c.up.railway.app` | `staging` |
| Production | `main` | `https://map.parkdex.app` | `https://api-production-e72df.up.railway.app` | `main` |

The app uses separate long lived Railway environments and Neon branches for staging and production. The API runs migrations during Railway pre-deploy. Routine releases reuse those resources.
