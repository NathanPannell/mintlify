## Executive summary

Bookhop builds as a Vite static app, but the source repository does not configure a staging or production host. `npm run preview` serves a local build for review; it does not publish the app. The reviewed checkout has no Git remote, GitHub Actions workflow, Vercel, Railway, or Cloudflare deployment configuration.

## Agent context

## Run locally

From PowerShell:

```powershell
Set-Location C:\repo\bookhop-workspace\bookhop
npm ci
npm run dev
```

Open `http://localhost:5173`. The development server uses the Vite script in `package.json`.

To build and review the production-shaped static output locally:

```powershell
Set-Location C:\repo\bookhop-workspace\bookhop
npm run build
npm run preview
```

Run the build before `npm run preview`. The preview command serves the generated files locally. It does not create a deployment or configure a domain.

## Staging and production

The source repository has no staging environment, production branch mapping, environment-variable list, host project ID, or deploy command. No Railway or Cloudflare mapping is present. The app has no API or database connection to configure.

Do not infer a production deploy from the local preview command. If you add hosting later, first record the selected host, project, domain, release branch, and rollback procedure in the repository. Confirm that direct page reloads work and that the product's browser-local progress behavior is expected on the hosted domain. A different domain or browser profile has separate `localStorage`.
