## Executive summary

Jev Hackathon is a static event landing page for Saturday, November 14, 2026 at the University of Victoria Hickman Building in Victoria, British Columbia. It is built from static HTML, CSS, and small vanilla JavaScript, then hosted on Vercel. The checked production branch is `main`; `staging` is a separate public review site. The site has no backend, database, analytics, or participant data collection. The organizer has not supplied a registration URL.

On September 29, 2026, an HTTP HEAD check returned `200` for both [production](https://www.jevhackathon.com/) and [staging](https://staging.jevhackathon.com/). Staging returned `X-Robots-Tag: noindex, nofollow, noarchive`. These checks confirm the hosts responded at that time. They do not confirm which Git commit is currently deployed.

## Product scope

The page explains the confirmed date and venue, lets visitors save the date with a calendar file, and showcases six examples of projects built with Jev. It does not collect registrations. Do not add a start time, price, eligibility rules, team size, prizes, judges, sponsors, or amenities without organizer confirmation. The event date and venue are the only facts currently included in Event structured data.

The showcase cards use creator names and linked public posts. The transaction sorting card is identified as a design concept because its creator clarified it is not a working Jev implementation. The self-driving demo is a simulation. Treat the showcase as examples, not as proof that the creators are attending or endorsing the event.

## Architecture and local preview

The repository contains ready-to-serve assets in `dist/`. `node scripts/build.mjs` copies those files into Vercel's configured `out/` publish directory and adds noindex metadata to non-production builds. There is no package manifest or install step. To serve the current `dist/` directory locally:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Run the repository checks with `node scripts/check.mjs` and `node --check dist/script.js`. The build command is `node scripts/build.mjs`.
