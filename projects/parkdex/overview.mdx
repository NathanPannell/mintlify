## Executive summary

Parkdex is the current field app in the `NathanPannell/parkdex-kip` repository. Kip is its mascot. The app is a Vite and Capacitor project with an offline map and park collection, Android support, and source code for account, feedback, content, and photo services. Its deployment guide describes Vercel, Neon, and Cloudflare. It does not describe a Railway service.

The repository README still describes the app as having no accounts or network sync, while the inspected staging tree includes account screens, API routes, database migrations, and a delivery guide for account services. Check the exact release SHA when you need to know which capabilities are active. Source code and delivery instructions are pinned below to the staging commit inspected on September 29, 2026.

## What runs where

The Vercel project serves the app and its Node API routes. Neon stores application data. Cloudflare runs the private photo service and stores private account photos in separate staging and production buckets. Public map and artwork files are served from the content release on Cloudflare R2. Cloudflare Pages is not the current frontend deployment path in this repository.

The public content package has a versioned manifest. Production reads the `main` content channel and keeps its curated catalogue. The delivery guide warns against replaying the historical public content bootstrap against production Neon.

For branch rules, provider configuration, previews, and exact release steps, see [Parkdex deployment](/projects/parkdex/deployment).
