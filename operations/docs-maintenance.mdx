## Executive summary

This site is a Mintlify documentation repository, `NathanPannell/mintlify`. Write and review changes on a branch, validate the MDX and navigation, test the hosted preview, and merge to `main` to publish through the existing Mintlify GitHub integration. The documentation site has its own lifecycle; it does not deploy any of the applications it describes.

Mintlify's connected repository and `main` branch were inspected in the dashboard on September 29, 2026. PR previews are enabled, and preview authentication is enabled. Preserve the existing access settings.

## Edit and validate

```powershell
npm ci
npm run check
npx mint validate
npx mint broken-links
npm run dev
```

The pinned Mintlify CLI is declared in `package.json`. Run commands from the folder containing `docs.json`. Local search can require Mintlify CLI sign-in; inability to use authenticated local search is distinct from an MDX rendering failure.

Every published page must have a title, description, and first heading of `Executive summary`. Put exact operational details and source references below that summary. Add new pages to navigation and link them from the relevant project overview.

## Who publishes what

| Step | Mechanism |
| --- | --- |
| Content contract check on PRs and pushes | GitHub Actions runs the Node validator |
| Full Mintlify build and link validation before delivery | Operator or agent runs the pinned CLI |
| Hosted preview for the feature branch | Mintlify preview deployment, through the enabled PR integration or documented preview API |
| Review and merge | GitHub PR review and merge |
| Hosted production build after a push to `main` | Mintlify GitHub integration |
| Exact deployment and browser verification | Operator or agent checks the deployment record and rendered site |

No Neon database, Railway service, Vercel deployment, Cloudflare Worker, or Play release is created by this documentation repository's checks.

## Optional API recovery

When the integration needs a deliberate retry, Mintlify documents a server-side admin API. Use an existing authorized credential through its private loader. Never paste its value into a command, tracked file, browser screenshot, or PR.

- [Trigger a preview](https://www.mintlify.com/docs/api/preview/trigger): request a build of a named branch.
- [Trigger an update](https://www.mintlify.com/docs/api/update/trigger): request a build of the configured deployment branch.
- [Read deployment status](https://www.mintlify.com/docs/api/update/status): confirm completion and inspect the built commit.

Keep any returned status ID with the delivery evidence. An accepted API request does not establish a successful deployment. Do not add recurring retries just to compensate for a one-time failure.

## Troubleshooting

- **Page returns 404:** confirm its exact slug is present in `docs.json`, its MDX file exists, and the deployed revision includes it.
- **Build fails:** inspect the deployment's error and the first local validation error. Check MDX syntax, frontmatter, and navigation before retrying.
- **Site still shows the starter:** inspect the connected repository, branch, latest build, and current revision. Do not update an unrelated Mintlify project.
- **Preview asks for sign-in:** use an authorized Mintlify organization account. Do not disable preview authentication to make verification easier.
- **Source link requires access:** private GitHub sources require appropriate repository access. The page must still explain the relevant procedure and evidence limits.
- **API key expired:** obtain a replacement through the approved credential workflow. Keep the old credential value out of logs and do not silently expand its permissions.

## Evidence

Repository files define the content checks. Mintlify dashboard Git and General settings establish the connected `main` branch and preview configuration. Mintlify's [official quickstart](https://www.mintlify.com/docs/quickstart) describes the repository-to-site publishing model. The final delivery record must identify the actual built commit and verified URL.
