# Design system

## Existing visual authority

Preserve the repository's native Mintlify mint theme. This task replaces starter content and navigation, not the framework or interaction system. The surface is for reading and finding operational information.

## Tokens and components

- Theme: mint
- Primary: #16734B
- Light accent: #34D399
- Dark accent: #16734B
- Typography, body measure, spacing, borders, theme switching, mobile navigation, and accessible controls: native Mintlify theme defaults.
- Branding: Project handbook text identity and a simple book favicon.
- Content components: headings, paragraphs, tables, lists, linked source references, and fenced code blocks.

## Reading structure

Every page begins with Executive summary. Detailed agent context, commands, and evidence follow. Navigation groups are Start here, seven projects, and Operations. Current and Legacy Parkdex are separate, with the landing page documented under current Parkdex.

## Review requirements

Verify deployed navigation, readable tables, code copying, summary placement, internal links, and mobile menu behavior. Keep native keyboard focus and theme behavior. Authentication is an existing product access control and must remain intact.
